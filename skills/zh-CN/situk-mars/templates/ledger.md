个人去重键由 `decision_id + approved_item_id + bot_id + change_type` 构成，可规范化后取 hash。一个批准包含同一机器人多件成果时，各件事项 ID 不同，不得误去重；同一事项重试至多入账一次。旧键保留 legacy 映射，不换键重放。身份、事件和事项稳定标识不以名字、行号或路径生成。

每个事件同时展示：名义分池、全员名义分摊、各人超帽未计、全员实际入账。允许实际入账小于名义分池，不把缺口分给别人。

未完成登记：<已完成 entry / 未完成 entry / 原因 / 同 decision_id 的对账重试计划>。多文件写入失败不能报“全部完成”，重复执行先查已存在 entry 与确切批准值，不重复加分。

更正以新批准、新追加流水表达每人“新应实记累计－原已实记累计”，可以是负数；不得覆写历史或重发整个分池。影响晋衔、席位或其他原周期名额时，整组列待裁；未经批准维持原正式账。

对账记录只追加：<无关联复核者 / 时间 / 批准值与流水及汇总 / 差异 / 处理状态>。本地 hash 链只是帮助发现改动，不等于外部公证或宿主权限隔离。
