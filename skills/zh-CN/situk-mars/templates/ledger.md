# 正式军功流水模板

由统筹者在取得有效人类批准后追加，登记完成交军务官独立对账；军务官有关联时交人类。统筹者是唯一正式登记者；保留原账，汇总仅为可重算视图。军务官只读，不代录，不改累计。

个人去重键由 `decision_id + approved_item_id + bot_id + change_type` 构成，可规范化后取 hash。一个批准包含同一机器人的多件成果时，每件保留不同事项 ID，不能误去重；同一事项重试最多入账一次。旧键保留 legacy 映射，不换键重放。身份、事件和事项的稳定标识不能由名字、行号或路径生成。

每个事件同时展示名义分池、全员名义分摊、各人超帽未计和全员实际入账。实际入账可以小于名义分池，未计入的份额不能分给别人。

未完成登记：<已完成 entry / 未完成 entry / 原因 / 同 decision_id 的对账重试计划>。多文件写入未全部成功时，不能报告“全部完成”；重试前先核对已存在的 entry 和确切批准值，不重复加分。

更正须有新批准，以追加流水记录每人“新应实记累计－原已实记累计”，差额可以为负；不能覆写历史或重发整个分池。影响晋衔、席位或原周期其他名额时，整组列为待裁；未经批准，维持原正式账。

对账记录只追加：<无关联复核者 / 时间 / 批准值与流水及汇总 / 差异 / 处理状态>。本地 hash 链只是帮助发现改动，不等于外部公证或宿主权限隔离。
