# 军功周报模板

由人类手动要求后生成；本模板不创建、启用、修改或触发 routine。军务官写自己的周报草案，正式账仍由元帅按人类批准登记。

- `weekly_id` / `rule_version` / 生成时间：<ID / 版本 / 含时区>
- 汇报周期：<ISO 周>
- 覆盖区间：<Asia/Singapore 周一 00:00 至下周一 00:00>
- 周期状态：<闭合终审 / 当周预审待闭合>
- 已读取：<具体目录、记录 ID、时间范围、读取时间>
- 未覆盖及读取失败：<逐项；不能以未读当无事项>
- 花名册基数：<已核实人数 / 未核人数>；本期无新事项 <N> 人。

| 四种状态 | 本周事项 | 是否计入正式累计 |
|---|---|---|
| 机器人自报 | <待核 event/report> | 否 |
| 证据已核实 | <review 结论与建议等级> | 否 |
| 人类已批准 | <decision/item；其中已登记/尚未登记> | 尚未登记的项目不计分 |
| 正式账已登记 | <entry、确切实记、独立对账状态> | 是；差异另列异常 |

## 待我拍板

<逐项列：确切提案版本、分值/份额、原周期、回避、晋衔/席位及待补批准。不把争议塞进汇总分。>

## 异常、未完成与更正

<超帽零分但有贡献；缺采用证据；重复/相似事件；已批未入账；登记不完整；独立对账差异；实际名字未知或同步受阻；旧决定晚到；更正依赖。每项附责任边界和下一步。>

## 岗位观察

<只依据实际委托和交付，列重复劳动、职责缺口、可复用能力及调整建议。无派活不视为低绩效；不自动新增岗位、降级、冻结、改职责或改调度。>

结论状态：<COMPLETE / EMPTY / PARTIAL / BLOCKED>。EMPTY 仅适用于范围完整读取且无新事项；当周未闭合不能正式记功或据此晋衔。读取不全时写 PARTIAL，不能宣称全员无贡献。
