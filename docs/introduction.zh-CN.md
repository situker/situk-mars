# situk-MARS｜军衔制机器人组织系统

**让机器人的功劳有据可查，让奖赏由人拍板。**

机器人越来越多，谁真正交付了东西，谁的成果被采用，谁只是说得多，往往混在聊天记录里。situk-MARS｜军衔制机器人组织系统把这些问题整理成一套 GrokBot 军衔制奖赏 Skill：用可打开的交付、明确验收和采用凭据论功，不按消息数、在线时长或自我表扬打分。

它设置两个治理岗位：Commander 归集战报，按有效批准唯一登记；军务官独立核证、查重、核算分摊和周帽，登记后再对账。人类负责人保留最终批准权。军务官本人或双方共同关联的事项交人类处理，不靠机器人互相点赞过关。

一轮流程是报功、核功、批准、记功、授衔、周报。同一成果只有一个分池，协作者按贡献分摊；迟报不能换周躲帽。正式积分与十级普通军衔分开：达到条件先成为候选，具体晋衔另批。元帅是 0～1 席特授头衔，不赠分、不扩权。奖章可在榜单展示，名字后缀只生成待办。

每周三份材料让负责人看清成果、已记奖赏、已批未登和待拍板事项，并观察重复劳动、职责缺口与可复用资产。先复用现有岗位，不因评奖自动补岗。

项目提供中英 Skill、规则、模板和可选 Python 核算器，先支持 GrokBot 文档工作流。虚构演练可以完整跑通六步；脚本不能认证真人或判断证据真伪。本版不建机器人、不自动改名、不动 routine；复杂更正和处分仍走人工模板。
