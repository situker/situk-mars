# Changelog

## 0.2.0 — 2026-10-26

First public release of **situk-MARS — Situk Merit-based Agent Rank System**.

- Freeze the reviewed merit rules: reports, independent review, exact human decisions, recording, rank conferral, and weekly reports.
- Provide complete English and Simplified Chinese Skill packs, templates, architecture diagrams and introductions.
- Preserve one-event pools, conserved collaborative shares, original-week caps, conflict handling, separate rank approvals and a zero-bonus Marshal appointment.
- Add localized synthetic exercise documents and display-name labels without changing numeric award or promotion rules.
- Include local regression tests, reproducible language packages and MIT licensing.

The release does not create live bots, install into other bots, rename profiles, enforce platform ACLs or schedule routines. Complex corrections, discipline and exceptional actions remain manual template workflows.
